Blätter, von denen jedes sich selbst nachrechnet

Kein Baukasten, keine Bibliothek, kein Build: jedes Stück hier ist eine einzelne HTML-Datei, die man weitergeben kann und die dann noch funktioniert. Und jedes trägt einen eingebauten Prüflauf, der das eigene Verfahren gegen eine unabhängige Rechnung stellt — erschöpfend, wo das bezahlbar ist. Das ist der eigentliche Inhalt der Sammlung: nicht die Algorithmen, sondern der Nachweis, dass sie stimmen.

je ein Repo, je ein Prüflauf
Beweis statt Behauptung — auch hier

Eine Sammelseite, die auf tote Adressen zeigt, ist schlimmer als keine. Der Prüflauf holt deshalb jedes einzelne Blatt und rechnet nach, was sich nachrechnen lässt: ist die Adresse erreichbar, trägt die Seite den erwarteten Titel, verweist sie zurück auf diese Sammelseite, und hat sie — wo es einen gibt — ihren eigenen Prüfknopf noch an Bord. Genau die Art Drift, die ein Netz aus 210 Querverweisen unbemerkt ansammelt.

Wie diese Blätter gebaut sind

Eine Datei

Kein Build, kein Paketmanager, keine externe Zeile Code. Ein Blatt muss einzeln weitergegeben werden können und dann noch laufen — im Zweifel wird Logik doppelt geschrieben, statt eine Abhängigkeit einzuführen.

Nichts verlässt den Browser

Alles wird lokal gerechnet: keine Server, keine Zählpixel, keine Anmeldung. Was eingegeben wird, bleibt auf dem Gerät.

Eingebauter Prüflauf

Jedes Blatt stellt sein Verfahren gegen eine unabhängige Referenz — die langsame Rechnung, eine zweite Implementierung, ein Literaturwert. Wo erschöpfend bezahlbar ist, wird erschöpfend gerechnet statt gestichprobt.

Ehrliches README

Jedes Repo hat einen Abschnitt „Was mich das gekostet hat": die echten Fehler beim Bauen, mit Messwerten, auch die unbequemen. Mehrfach hat der eigene Prüflauf nicht den Code korrigiert, sondern meine Erklärung.
